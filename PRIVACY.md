# Privacy Policy: Kiosk Exit Button

Last updated: November 15, 2026

Kiosk Exit Button does not collect, store, transmit or sell any personal data or browsing data.

What is stored
The extension saves only your button configuration (type, text, color, image, position, size and auto-hide settings). This is stored locally on your device using Chrome's storage API and is never sent anywhere.

Permissions
The extension requests access to all websites solely to display the exit button on top of the page shown in kiosk mode. The only change it makes to a page is adding that button and its styling. It does not read or record page content.

Third parties
No data is shared with third parties. The extension contains no analytics, tracking or advertising code, and all of its files are bundled with it: it makes no network requests of its own. The settings page contains a "Buy me a coffee" link, which opens an external website only if you click it.
