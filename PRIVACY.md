# Privacy Policy: Kiosk Exit Button

Last updated: October 30, 2026

Kiosk Exit Button does not collect, store, transmit or sell any personal data or browsing data.

What is stored
The extension saves only your button configuration (type, text, color, image, position, size and auto-hide settings). This is stored locally on your device using Chrome's storage API and is never sent anywhere.

Permissions
The extension requests access to all websites solely to display the exit button on top of the page shown in kiosk mode. It does not read, record or modify page content.

Third parties
No data is shared with third parties. The extension contains no analytics, tracking or advertising code.
